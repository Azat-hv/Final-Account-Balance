# Final-Account-Balance
This project provides a SQL Server solution for the "Final Account Balance" problem, frequently asked in PayPal data analyst and data engineer interviews. The repository includes a custom 100-row sample dataset simulating real-world banking transactions, such as deposits and withdrawals, across 10 different accounts. To solve the problem, the project utilizes the SQL GROUP BY clause combined with the conditional SUM(CASE WHEN...) function. This algorithm calculates the net balance for each user by adding deposit amounts and subtracting withdrawal amounts. The provided script sets up the database schema, inserts the mock data, and demonstrates the exact query needed to calculate the final account balances correctly.

This query algorithm was written entirely by my own effort, without any assistance from artificial intelligence.
